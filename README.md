学習用のリポジトリ。言語処理系の出力やOSの基本的な仕組みを手を動かして学ぶゴミ置き場です。

## gdbの基本的な使い方

コマンドは覚えられないので基本的にはMakefileに記述されていきます.

`make debug`をすることによってgdbとqemuで実行されるベアメタルプログラムのzellijペインが開きます

### 基本

| コマンド | 説明 | 使用例・用途 |
|-----------|------|--------------|
| break 関数名/アドレス (b) | ブレークポイントを設定 | `b _start` や `b main`、あるいは例外ハンドラの先頭で止める時などに使います。 |
| continue (c) | 次のブレークポイントまで一気に実行 | 起動時の初期化コードを飛ばして、目的の処理まで進めたい時に使います。 |
| step (s) | C言語のソースを1行進める（関数の中に入る） | 自作した関数（例：uart_putc）の内部挙動を追いたい時に使います。 |
| next (n) | C言語のソースを1行進める（関数の中に入らない） | 関数の内部には興味がなく、呼び出しの戻り値だけ確認して次に行きたい時に使います。 |
| stepi (si) | アセンブリ命令を1命令進める | C言語の1行がどのアセンブリに変換され、どう動くかをミクロに観察するOS開発の必須コマンドです。 |
| nexti (ni) | アセンブリ命令を1命令進める（関数呼び出しはスキップ） | `jal` や `call` などのジャンプ命令の中に入らず、次の命令へ進みます。 |

### レジスタの確認と操作

ベアメタル環境では、「今どのCPUコアにいるか」「割り込みは有効か」など、すべてがレジスタ（特にRISC-VのCSR: Control and Status Registers）に保存されています。

- `info registers (i r)`: 汎用レジスタ（a0〜a7, sp, ra など）の現在の値を一覧表示します。

- `print $レジスタ名 (p)`: 特定のレジスタの値をピンポイントで表示します。
  - 例: `p/x $a0` (関数呼び出しの第1引数や戻り値を16進数で確認)

  - 例: `p/x $mstatus` (RISC-Vの特権モードのステータスレジスタを16進数で確認)

- `set $レジスタ名 = 値`: 実行中にレジスタの値を強制的に書き換えます。

  - 例: `set $a0 = 1` (エラー分岐のテストなどで、関数が返す値を無理やり書き換えて挙動を見る時に便利です)

## risc-vでC ABIに従って作ったスタックフレーム

### risc-vの場合

```
|<---- 8 byte(64bit) ---->|


(Low Address)
+-------------------------+ <--- 【sp (スタックポインタ) はここを指す！】
| ローカル変数 2          | <--- (fp - 32)
+-------------------------+
| ローカル変数 1          | <--- (fp - 24)
+-------------------------+
| Saved s0 (旧fp)         | <--- プロローグで手動で保存した旧s0 (fp - 16)
+-------------------------+
| Saved ra (旧ra)         | <--- 【重要】プロローグで手動で保存した戻り先！ (fp - 8)
+=========================+ <--- 【s0 / fp (フレームポインタ) はここを指す！】
| 前の関数のスタック      |
+-------------------------+
(High Address)
```

### x86_64の場合

```
(Low Address)
+-------------------------+ <--- 【rsp (スタックポインタ) はここを指す！】
| ローカル変数 2          |
+-------------------------+
| ローカル変数 1          |
+-------------------------+
| Saved rbp (旧rbp)       | <--- 【rbp (ベースポインタ) はここを指す！】
+-------------------------+
| Return Address (旧rip)  | <--- 【重要】call命令が自動でPushした戻り先！
+=========================+ <--- 関数呼び出し(call)の直前の境界
| 引数7, 引数8... (※)    |
+-------------------------+
| 前の関数のスタック      |
+-------------------------+
(High Address)
```

## risc-v命令

### レジスタの内容をレジスタに書き込む

```asm
mv <書き込み先レジスタ>, <レジスタ>
```

### メモリの内容をレジスタに書き込む

```asm
ld <書き込み先レジスタ>, offset(<書き込み先のメモリアドレスが格納されたレジスタ>)
```

```asm
lw <書き込み先レジスタ>, offset(<書き込み先のメモリアドレスが格納されたレジスタ>)
```

### レジスタの内容をメモリに書き込む

8 byte 書き込み (store double)

```asm
sd <書き込みたい値の入ったレジスタ>, offset(<書き込み先のメモリアドレスが格納されたレジスタ>)
```

4 byte 書き込み (store word)
```asm
sw <書き込みたい値の入ったレジスタ>, offset(<書き込み先のメモリアドレスが格納されたレジスタ>)
```
